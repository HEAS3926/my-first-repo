# 我的第一个仓库

这是我在学习 Git 和 GitHub 过程中创建的第一个远程仓库。

## 我已经学会的操作

- 克隆别人的仓库（git clone）
- 修改文件并观察工作区状态变化
- 把改动提交到本地仓库（git commit）
- 配置 SSH 密钥，免密码推送（这一步刚完成）

## 接下来要练的

- 推送到远程仓库（git push）
- 拉取远程的更新（git pull）
- 创建分支并合并（git branch / git merge）
